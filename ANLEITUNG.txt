LADECHECK – PWA EINRICHTUNG

1. Lade diese drei Dateien in dasselbe GitHub-Verzeichnis wie index.html:
   - manifest.json
   - service-worker.js
   - icon.svg

2. In index.html direkt NACH <meta name="viewport"...> diese Zeilen einfügen:

<link rel="manifest" href="manifest.json">
<meta name="theme-color" content="#0E6E63">
<meta name="apple-mobile-web-app-capable" content="yes">
<meta name="apple-mobile-web-app-status-bar-style" content="default">
<meta name="apple-mobile-web-app-title" content="Ladecheck">
<link rel="apple-touch-icon" href="icon.svg">

3. Direkt VOR </body> diese Zeilen einfügen:

<script>
if ("serviceWorker" in navigator) {
  window.addEventListener("load", function () {
    navigator.serviceWorker.register("./service-worker.js")
      .then(function () { console.log("Ladecheck offline bereit"); })
      .catch(function (err) { console.error("Service Worker:", err); });
  });
}
</script>

4. Änderungen in GitHub speichern/committen.

5. Die GitHub-Pages-Adresse auf dem iPhone in Safari öffnen.

6. In Safari auf Teilen → "Zum Home-Bildschirm" bzw. "Als Web-App hinzufügen" → Hinzufügen.

HINWEIS:
- Die App braucht eine HTTPS-Adresse. GitHub Pages erfüllt das.
- Das SVG-Icon funktioniert als Web-App-Icon in modernen Browsern. Falls iOS für das Home-Screen-Icon ein PNG bevorzugt, kann später zusätzlich ein 180x180 PNG ergänzt werden.
- Der Service Worker sorgt für Offline-/Cache-Unterstützung. Die Tarifdaten selbst sind weiterhin die im Code hinterlegten Beispielwerte.
